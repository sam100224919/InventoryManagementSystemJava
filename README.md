# Inventory Management System

A Java-based inventory management application demonstrating object-oriented programming, collections, CRUD operations, searching, sorting, and inventory logic.

## Features

- Add inventory items
- Remove inventory items
- Update item information
- Search inventory
- Sort inventory
- Track item quantities
- Calculate inventory value
- Support different item types

## Technologies

- Java
- Object-Oriented Programming
- Java Collections Framework
- IntelliJ IDEA
- Git / GitHub
